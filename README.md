# QR Code Generator

A simple and user-friendly QR Code Generator that allows users to generate QR codes from text, URLs, and other supported information. The project provides a quick and convenient way to convert input data into a scannable QR code.

## ✨ Features

- Generate QR codes from text or URLs.
- Simple and intuitive user interface.
- Quick QR code generation.
- Responsive design for different screen sizes.
- Easy to use and beginner-friendly.
-  Download QR codes as PNG images

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 How It Works

1. Enter your text or URL in the input field.
2. Click the Generate QR Code button.
3. Your QR code will be displayed on the screen.
4. Scan the generated QR code using your smartphone.
